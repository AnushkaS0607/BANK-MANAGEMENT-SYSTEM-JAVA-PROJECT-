# ATM Simulator

## Problem Statement

The ATM Simulator is developed to simulate common ATM operations through
a Java-based application. The system allows a user to register, create
account and card details, log in using a card number and PIN, and
perform banking transactions. The application stores relevant
information in a MySQL database.

## Scope of the Project

The project covers: - User registration and account creation - Storage
of personal and additional applicant information - Card number and PIN
management - User authentication - Deposit and withdrawal - Fast Cash -
Balance Enquiry - Mini Statement - PIN Change - Transaction record
storage - Java, JDBC, and MySQL database integration

The project is an academic ATM simulation and is not intended to operate
as a real banking system.

## Target Users

-   Students learning Java and Java Swing
-   Students learning JDBC and MySQL database connectivity
-   Developers studying a basic ATM and banking application
-   Academic project evaluators and instructors

## High-Level Features

-   Multi-step signup process
-   Personal and additional information collection
-   Account and card creation
-   Card number and PIN based authentication
-   Deposit
-   Withdraw
-   Fast Cash
-   Balance Enquiry
-   Mini Statement
-   PIN Change
-   MySQL database integration
-   Transaction record management
